Put your anime pictures in this folder (.jpg, .jpeg, .png, .webp, .avif or .gif).

- They are found automatically. No code changes needed.
- One picture = a fixed background. Several = a slideshow that fades between them.
- For a sharp result on big screens, use pictures about 1920 px wide or larger.
- To keep file sizes reasonable, try to keep each picture under 1.5 MB.
- Set BACKGROUND_MODE=random in your .env for one random picture per page load instead.

Restart "python manage.py runserver" after adding pictures if they don't appear.

Copyright note: pictures you downloaded from the internet usually belong to their artists.
That's fine on your own computer. Before you publish the site or push it to a public
GitHub repository, check each picture's license, or use your own / freely licensed art.
